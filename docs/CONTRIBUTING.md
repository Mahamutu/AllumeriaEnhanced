# Contributing

Contributions for bug fixes, compatibility improvements, documentation and
noncommercial shader experiments are welcome.

1. Do not commit Allumeria assemblies, original game shaders or other game-owned
   assets.
2. Keep Aurora and Classic independently selectable.
3. Preserve custom pack icons and manifest settings.
4. Compile every changed GLSL program in an OpenGL 3.3 context.
5. Test affected scenes in game, including day, night and underwater rendering
   when relevant.
6. Describe the visible before/after behaviour and the hardware used for tests.

By contributing, you agree that your contribution is provided under the
repository's PolyForm Noncommercial License 1.0.0. Do not submit material you
do not have permission to redistribute under those terms.
