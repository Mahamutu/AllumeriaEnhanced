# Allumeria Enhanced 0.13.0

This release focuses on user control and UI integration.

## Installation

Download `Allumeria-Enhanced-0.13.0.zip` and extract it directly into the
folder containing `Allumeria.exe`. Confirm merging the `mods` folder,
then fully restart the game.

## Important

- The loader DLL changed, so F8 alone is not enough for this update.
- F8 continues to reload shader edits after the restarted game loads 0.13.0.
- Aurora's moon god rays default to 135% and can be adjusted from 0-250%.
- Each pack can provide its own 16x16 `icon.png` and selected settings in
  its `pack.json`.
- This project uses raster techniques, shadow maps and SSR; it does not claim
  hardware ray tracing.

The Polish language pack is a separate download:
`Allumeria-Polish-Translation-pl-PL-0.15.zip`.
